# Obtain the 2024 IPUMS CPS telework data

Follow the sample selection, variables, definitions, and replication steps in [the post README](../README.md). Save the matching compressed fixed-width file and DDI XML as `raw/cps_00002.dat.gz` and `raw/cps_00002.xml`, or adjust the script filenames to your own extract number.

Raw files are local inputs and are excluded from publication. The article uses all twelve 2024 Basic Monthly samples, not the older 2019/2024 unemployment extract.
